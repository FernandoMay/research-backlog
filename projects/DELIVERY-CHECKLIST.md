# Submission Delivery Checklist

- [ ] Official CFP, publisher, page limit, and submission portal verified
- [ ] Title and abstract match the implemented method
- [ ] Author name, affiliation, email, and ORCID match across all files
- [ ] No simultaneous submission to another venue
- [ ] Dataset license and provenance recorded
- [ ] Random seeds fixed and reported
- [ ] Baselines implemented, not only described
- [ ] At least one ablation or sensitivity analysis executed
- [ ] Confidence intervals or repeated-trial dispersion reported
- [ ] Negative results and limitations included
- [ ] `pytest` or equivalent passes in a clean environment
- [ ] Simulator completes in Docker or documented environment
- [ ] Figures regenerated from current metrics
- [ ] Paper PDF compiled from current source
- [ ] Presentation PDF compiled from current source
- [ ] Camera-ready archive contains source, PDF, figures, and README
