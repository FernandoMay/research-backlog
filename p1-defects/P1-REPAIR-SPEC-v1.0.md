# P1 Repair Specification v1.0

**Date:** 2026-09-30
**Status:** specification only. **No repository has been modified. No repair has begun.**
**Inputs:** the six frozen defect reports in this directory, plus `SWEEP-CONSOLIDATION.md`.
**Governs:** every subsequent change to the seven audited packages and to the manuscripts that describe them.

---

## 0. The rule this specification exists to enforce

> **A repair is not validated because it produces different numbers. It is validated because it restores a property that was specified in advance.**

Every entry below therefore has three parts: the **property**, a **pre-fix falsifier** that must fail on the current code and pass after the change, and an explicit list of **non-criteria** — things that can change without the repair counting as done.

The pre-fix falsifier is the load-bearing part. It must be executable, it must fail today, and it must be capable of passing. A falsifier that cannot fail is not a test.

## 1. Repair classes

| class | meaning | touches code? | cases |
|---|---|---|---|
| **R1** | The artifact did not implement the property it declared. | yes | LEO NSGA-II, SGN, ISAC, Quantum (operations) |
| **R2** | The code is sound; the experiment does not identify the question it asks of itself. | sometimes | LEO extended ablation, CRL, Quantum (design) |
| **R3** | The results may be valid; the document, the names, or the provenance are not. | **no** | i01 (document), QCE (terminology) |

**R3 must not produce a code change.** Three of the eight rows are not code bugs. Treating them as code bugs would convert a naming problem into an unnecessary rewrite, and would destroy the evidence that the underlying numbers were correct — which is the only reason those cases are classified separately from ISAC.

## 2. The repair matrix

| # | case | class | property to restore | success criterion |
|---|---|---|---|---|
| 1 | LEO NSGA-II | R1 | the chromosome causally determines the objectives it is scored on | under a fixed environment and a reseeded RNG, two different weight vectors yield different objective tuples |
| 2 | LEO extended ablation | R2 | the ablation isolates the NSGA-II factor and nothing else | the with/without arms differ in exactly one factor, and the arm labelled "NSGA-II" actually invokes the NSGA-II path |
| 3 | `i01` comparison | R2 | all compared methods optimise the same stated objective | the baselines' objective functions reference the same quantities as the proposed method's, or the paper stops calling it a comparison |
| 3 | `i01` document | R3 | every published number corresponds to the published run | abstract, table, and conclusion are regenerated from one committed run at a committed seed |
| 4 | CRL baseline | R2 | the baseline experiences the stressor the treatment does | a failed agent can change the baseline's completion metric; the stressed configuration is reachable by parameter |
| 5 | QCE terminology | R3 | every methodological label names a mechanism that executes | no occurrence of "RL", "reinforcement learning", "Pareto", "variational" or "QAOA" survives without its actual mechanism disclosed adjacent to it |
| 6 | SGN codec | R1 | `decode(encode(payload)) == payload` | round-trip identity holds and reported bit accuracy is 1.0 in the no-noise case |
| 7 | ISAC validation | R1 | the validation evidence is independent of the bound it checks | the estimator consumes observations and forms a likelihood; the bound is computed from that estimator and never used to synthesise an observation |
| 8 | Quantum operations | R1 | named operations have the semantics their names carry | measurement samples, the optimiser is variational, the channel is trace-preserving |
| 8 | Quantum design | R2 | comparisons use matched instances and a non-dominated operating point | methods are evaluated on the same instances; the selected `p` is not strictly dominated |

## 3. The execution chain

Every repair follows the same seven stages. A stage may not be skipped, and a later stage may not compensate for a skipped earlier one.

```
PROPERTY
   ↓
PRE-FIX FALSIFIER          must fail on current code; record the failure output
   ↓
IMPLEMENTATION             the smallest change that could satisfy the property
   ↓
UNIT / INTEGRATION TEST    the falsifier, re-run; must now pass
   ↓
INDEPENDENT RE-RUN         fresh process, clean environment, committed seed
   ↓
ARTIFACT                   regenerated by the run, never hand-edited
   ↓
CLAIM RECONCILIATION       every published number traced to that artifact
```

The ordering that matters: the falsifier is written and **observed failing** before the implementation exists. A test authored after the fix, and never seen red, is not evidence of anything.

## 4. Per-case specification

### 1. LEO NSGA-II — R1

**Property.** The chromosome parameterises the objective function, as `paper/main.tex:121` states. Changing the chromosome under a fixed environment must change the evaluation.

**Pre-fix falsifier.** With the RNG reseeded immediately before each evaluation, evaluate two chromosomes differing only in `weights`, and assert the `(latency, resilience, coverage)` tuples differ.

*Current behaviour:* `nsga2_optimize` draws `latency`, `resilience` and `coverage` from `np.random.uniform` without reading `chrom`. Reseeded, the tuples are **identical** and the assertion fails. Without reseeding it would pass by accident, because the RNG advances between chromosomes — which is why the reseed is part of the test and not an afterthought.

**Implementation scope.** `nsga2_optimize` must receive the environment and route each chromosome through `compute_latency_ms` / `compute_resilience` / coverage, which already exist in the same file and are already used causally by the extended simulator.

**Non-criteria.**
- The `optimal_weights` triple changing. The current value is arbitrary by construction; a new one is equally arbitrary until the property holds.
- Any change to `metrics.json` that is not accompanied by a regenerated artifact.
- A Pareto front that "looks better".

**Downstream.** Rows 1 and 2 of the matrix are coupled. The ablation cannot be repaired meaningfully while the prior it is supposed to isolate is noise. Repair 1 first, then re-derive 2.

### 2. LEO extended ablation — R2

**Property.** The ablation varies exactly the NSGA-II factor.

**Pre-fix falsifiers.**
1. Assert the `ql` arm does **not** receive the output of `get_weights()`. *Currently it does* — `evaluate_strategy` is called with `weights=w` for every arm, so `main.tex:184`'s "without NSGA-II" arm is not without NSGA-II.
2. Assert the arm labelled "NSGA-II" invokes `nsga2_optimize`. *Currently the label maps to `router_mode == 'ga'`, which is `GAOptimizer`, a single-objective load balancer.*

**Implementation scope.** Either introduce a genuine no-prior arm, or stop labelling the genetic load balancer as NSGA-II. The second is R3 and belongs with row 5.

### 3. `i01` — R2 and R3

**R2 pre-fix falsifier.** Assert `PSOOptimizer._evaluate` and `GAOptimizer._fitness` reference the same state quantities that `XINGOrchestrator._calculate_reward` references — `energy_level`, `queue_length`, `task.priority`, `task.computational_load`. *Currently they reference none of them; the two bodies are byte-identical to each other and read only `sat_loads`.*

**R3 pre-fix falsifiers.**
- Regenerate at the committed seed and assert the abstract's task count matches. *Currently 941 against a published 955.*
- Assert the conclusion asserts no improvement on any metric where the table shows a regression. *Currently it claims "significant improvements … in latency, deadline compliance, and execution efficiency" against a table of 28.07 s versus 0.40 s and 39.5% against 98.7%.*
- Assert every published quantity is derivable from a committed artifact. *Currently no artifact exists; the table exists only in the paper.*

**The provenance gap is a finding, not a hypothesis to be resolved by guessing.** A later code state, a different configuration, a different seed and a manual run are all consistent with the evidence, and none is established. The repair is to make the current run authoritative and to record that the prior numbers had no recorded provenance — not to attribute them to a cause.

### 4. CRL — R2

**Property.** The baseline experiences the stressor.

**Pre-fix falsifiers.**
1. Assert the without-CRL node advance consults agent state. *Currently `node.status = "completed"` is unconditional, so a `FAILED` agent's node completes anyway and the completion metric has no causal path from the stressor.*
2. Assert a stressed configuration is reachable by parameter. *Currently there is no `argparse`, no mode parameter, and both entry points are hardcoded; the stressed mode the paper names does not exist.*

**Non-criterion.** A non-zero `Total Modifications`. Making the CRL act more is not the property; making the baseline able to fail is.

### 5. QCE — R3, no code change

**Pre-fix falsifier.** A terminology audit with an explicit allowlist, run against `paper/en/main.tex`, `paper/zh/main.tex`, `README.md` and the presentation decks. For every occurrence of `reinforcement learning`, `\bRL\b`, `Pareto`, `variational` or `QAOA`, assert the actual mechanism is disclosed in the same sentence or the same paragraph.

*Currently failing:* the keyword list at line 30 carries "reinforcement learning" with no adjacent disclosure; the section title at line 266 is "Online RL Error Predictor"; line 244's honest "evaluates $2^{N_M} = 32$ configurations" contradicts the variational framing elsewhere in the same document; and "Pareto-optimal" in the abstract has no referent, since the routine returns a single point.

**Implementation scope.** None. Terminology only. `self.gamma = 0.9` being dead code is recorded but removing it is not part of this repair, because deleting it would erase the evidence of what the component was intended to be.

### 6. SGN — R1

**Property.** The codec is invertible.

**Pre-fix falsifier.** The cleanest in this specification:

```python
stego, n = method.encode(cover, secret)
recovered = method.decode(stego)
assert np.array_equal(recovered[:len(secret)], secret)
```

*Currently fails at ~0.50 for `LSBSteganography`.* `decode` applies `np.unpackbits` to masked pixel values, returning 8 bits per pixel where `encode` embedded 1. A second falsifier asserts `len(decode(encode(x)))` is consistent with `n_bits`.

**Scope boundary carried forward.** The mechanism is proven for LSB only. `GAN_Enc` and `Adaptive_JND` show the same symptom and use different decoders; their cause is **not established** and no repair is specified for them. If the round-trip test is extended to them and fails, the cause must be traced first, not assumed to be the same.

### 7. ISAC — R1

**Property.** The validation evidence is independent of the bound.

**Pre-fix falsifiers.**
1. **Static.** Assert the observation-generation path does not call `crlb_range` or `crlb_velocity`. *Currently line 147 does exactly that: `R_est = R_true + randn() * crlb_range(...)`.* This is the decisive test and it is a one-line grep against the estimator body.
2. Assert the noise path preserves the state norm. *Currently ‖ψ‖² falls to 0.5166 at noise 0.3 and 0.2822 at 0.5.*
3. Assert Figure 5's data is produced by a simulation function. *Currently `rd = np.random.randn(50, 50); rd[25, 15] = 100`.*

**Implementation scope.** An estimator consuming observations, forming a likelihood, and yielding a Fisher information matrix from which the bound is computed. The paper already states this derivation at line 178; the code does not perform it.

**Non-criteria.**
- Spectral efficiency rising above 4 bps/Hz. The number is not the property.
- A tighter agreement between simulated PE and the bound. Under a correct estimator, disagreement is the informative outcome.

**Consequential.** The σ²-versus-σ units defect cannot be observed until the circularity is removed. Fixing 1 will likely expose 2. That is expected and is not a second failure of the repair.

### 8. Quantum — R1 and R2

**R1 pre-fix falsifiers.**
1. *Measurement.* Assert the number of candidate bitstrings scored per evaluation is 1, or that candidates are drawn from the Born distribution. *Currently ten exact amplitudes are probed and the maximum is returned.*
2. *Variational.* Assert the parameter optimiser exposes a gradient or a classical-optimiser interface. *Currently $\gamma,\beta$ are uniform draws and the best of forty is kept.*
3. *Channel.* Assert the noise map is trace-preserving. *Currently the uniform term has squared norm $1/N$.*

**R2 pre-fix falsifiers.**
4. Assert QAOA and WalkSAT are evaluated on the same instance list. *Currently two disjoint sets of six, and the random baseline reuses the last WalkSAT instance through a leaked loop variable.*
5. Assert the selected `p` is not strictly dominated on both metrics. *Currently `p=1` beats `p=2` on satisfaction and gap, and the abstract names `p=2`.*

**Non-criteria.** Any change to the reported satisfaction ratios. The oracle and the random search both move those numbers; neither is the property.

## 5. What may not happen

- **No manuscript may be edited until every repair above has passed its falsifier and its artifact has been regenerated.** Several repairs will change numbers and several will only change names; mixing them now destroys the separation the sweep established.
- **No artifact may be hand-edited.** Every metrics file is produced by a run.
- **No report of a passing reproduction may be made before the simulator has actually been observed to run.** Four such claims were nearly made during the sweep. The check is whether the artifact file's contents changed, not whether the command exited zero.
- **No E1 row may be re-adjudicated.** These seven packages are a different corpus from the frozen dataset.
- **The embargo on `dsl-bank` is unaffected by this specification** and no row here touches it.

## 6. Sequencing

Repairs are ordered by dependency, not by severity.

1. **LEO NSGA-II (1)** — the ablation repair (2) is meaningless while the prior is noise.
2. **LEO extended ablation (2)** — re-derive after 1.
3. **SGN (6)** — the cleanest falsifier in the set, and it establishes the round-trip pattern the other codec work would follow.
4. **ISAC (7)** — the largest, and it will expose the units defect.
5. **Quantum (8)** — operations then design.
6. **CRL (4)** — requires a design decision about the baseline, not only an edit.
7. **`i01` R2 (3)** — requires choosing whether to change the baselines or the framing.
8. **QCE R3 (5) and `i01` R3 (3)** — no code, and can run in parallel with anything.

R3 rows are last not because they are least important but because they consume no experimental budget and should be applied to whatever the R1 and R2 repairs end up producing, not to the current numbers.

## 7. The methodological claim this specification preserves

> **The eight failure profiles are not eight severities of one defect. They are failures at different evidentiary layers.**

That is why rows 1 and 2 are separated although they are one repository, why SGN and QCE are both "the numbers are fine" and still require different repairs, and why three rows must not produce a code change at all. It is also why the E1 result stands as an integrity audit rather than a general ranking of scientific quality: a single score would have to be wrong about six of these eight cases.

**Acceptance of this specification is a precondition for touching any of the seven packages.**
