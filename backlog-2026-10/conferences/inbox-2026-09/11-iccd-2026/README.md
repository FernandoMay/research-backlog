## Track fit

Verbatim track titles from https://www.iccd-conf.com/2026/home.html, retrieved 2026-09-27.

| Verbatim track title | User research line that falls under it |
|---|---|
| `Track 1. Computing Systems` | multi-agent systems is not a listed topic; the track covers system architecture, co-design, virtual memory, storage, HPC and serverless |
| `Track 3. Hardware Architectures` | BCI/cognitive interfaces, distant fit only; the track's verbatim AI-related sub-topic is "Hardware acceleration for computing-intensive/data-intensive applications, such as machine learning, autonomous driving, robotics, quantum, neuromorphic, bio-inspired, etc" |
| `Track 4. Test, Verification, and Security` | payment/ledger systems are not a listed topic; the verbatim sub-topic is "Hardware security primitives and methodologies" |

ICCD is a computer architecture and hardware design conference. **None of the four recorded research lines is a good fit for its tracks**, and the 2026 submission window is closed in any case. It is recorded here because the invitation is genuine, not because it is a usable venue.

The site separately invites special session and tutorial proposals on "blockchains, machine learning techniques and applications, accelerators, hardware and software security, open-source design infrastructure, and quantum computing etc." Those proposal windows also closed, on 2 July and 4 July 2026.
