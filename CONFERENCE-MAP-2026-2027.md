## Submission Gate

Before submitting any package:

1. Verify the official CFP and whether the deadline is still open.
2. Match the manuscript template and page limit.
3. Run the repository from a clean environment.
4. Archive raw metrics, seed, command, environment lock, and figures.
5. Check that every result in the PDF appears in a generated artifact.
6. Prepare anonymized files if the venue is double-blind.
7. Never submit the same manuscript simultaneously to multiple venues.
