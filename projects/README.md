## Delivery Contract

Every project must contain:

- `src/` or `simulator/` with executable experiments
- `tests/` with deterministic unit and integration tests
- `data/` with generated metrics and provenance, never hand-edited results
- `figures/` generated by a script
- `paper/main.tex` and compiled PDF
- `pres/slides.tex` and compiled presentation
- `REPRODUCE.md` with exact commands, versions, seeds, and limitations
- `CITATION.cff` with ORCID `0009-0002-3953-5224`
- `Dockerfile` or a pinned environment specification

## Publication Rule

No paper claim is accepted unless the exact number is generated by the repository's current code and stored with the command, seed, environment, and dataset provenance.
